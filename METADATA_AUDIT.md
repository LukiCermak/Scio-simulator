# Metadata Audit

## Runtime metadata ponechat
- identifikátory otázky a baterie
- správnou odpověď a její odvozené varianty
- tematická pole pro Tutor, analytics a repair flow
- Tutor texty a vysvětlení
- pole pro doporučené repair filtry a revision priority

## Mimo runtime vrstvu přesouvat
- kurátorské poznámky
- auditní pomocná pole
- interní zdrojové reference, pokud nejsou potřeba v běhu aplikace

## Pravidlo
Pole zůstává v runtime jen tehdy, pokud ovlivňuje:
- UI
- review
- Tutor
- analytics
- repair flow
