# Validační Checklist

- aplikace se načte bez chyb
- základní režim načte všechny baterie
- hard režim načte všechny baterie
- lze spustit test a dokončit vyhodnocení
- review a Tutor se vykreslí
- repair flow funguje
- statistiky a progress se neztratí
- počty baterií a otázek odpovídají aktuálním datům
